# Android direction

Use Kotlin/Jetpack Compose with presentation/domain/data separation. Later
phases cover accessible online learning, local persistence, bounded downloads,
offline media and durable operation queues. Reconnect behavior needs versioned
idempotent reconciliation and explicit failure/conflict states. App signing,
SDK levels, store policies and privacy disclosures are release-time decisions.
Phase 0 has no Gradle wrapper or application tests; those gates are pending.
