# Operations direction

Production acceptance requires owned monitoring/alerts, error tracking, safe
structured logs, availability/latency/resource checks, backup/restore evidence
and deployment/rollback runbooks. Define recovery objectives and retention with
the owner before production. Test restore procedures against isolated data.
Private incident evidence, production endpoints, credentials and sensitive logs
stay outside this repository. This file is a plan, not an operational runbook
or a claim that any monitoring/backups exist.
